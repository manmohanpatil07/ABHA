# Digital Health Application

Based on the required architecture, this is a simplified React Native and Express.js full-stack application.

## Structure
- \`mobile/\`: React Native application
- \`backend/\`: Express.js application
- \`database/\`: MySQL schemas and seeds

## How to run
**Backend**
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`

**Mobile**
\`\`\`bash
cd mobile
npm install
npx react-native start
npx react-native run-android
\`\`\`
